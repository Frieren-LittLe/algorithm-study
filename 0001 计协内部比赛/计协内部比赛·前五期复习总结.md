# 计协内部比赛 · 前五期复习总结

一期到五期共 44 道题。CF231A 在二期、四期各出过一遍，去掉重复是 43 道不同的题，下文按 43 道统计。

## 分数怎么给的

难度按 1–100 打分：100 是 ICPC 区域赛压轴，1 是 hello world，2 是 A+B Problem。

为了不凭感觉乱给，分数是对着 Codeforces 难度分换算的：

| CF 难度分 | 本表分数 |
|---|---|
| 800 | 3–5 |
| 1000 | 8–10 |
| 1200 | 13–15 |
| 1400 | 18–20 |
| 1600 | 25–28 |
| 1800 | 35–36 |
| 1900 及以上 | 40 以上 |

区域赛压轴题在 CF 上通常 2600 分往上，换算过来是 80–100 分。前五期最高的两道是 CF1718A1（40 分）和 CF2280C（36 分），位置在 Div2 的 C 到 D 之间。

CF1873C 的分数只和「离最近那条边有多远」有关，不用写十层 if-else：

```cpp
for (int i = 0; i < 10; i++)
    for (int j = 0; j < 10; j++) {
        char c; cin >> c;
        if (c == 'X') {
            int d = min(min(i, 9 - i), min(j, 9 - j));   // 0~4
            score += d + 1;                              // 1~5
        }
    }
```

要记得：

- P1422 输出一位小数要 `cout << fixed << setprecision(1)`。只写 `setprecision(1)` 控制的是有效数字，5.5 之外的数会输出成 `6` 这种。
- P1980 是逐个数拆位，不是按数位统计。`for` 里套 `while (t) { ... t /= 10; }`，10⁶ × 6 次运算完全够。
- CF43B 大小写不敏感，进桶前统一转一种；信件里的空格不消耗字母，不能一起统计。
- CF1873C 的 `min(i, 9-i)` 得到 0–4，加 1 才是 1–5 分。网格下标从 0 开始这一步最容易错。
- U729737 的 `n = n * 2 / 3` 等价于 `n -= (n + 2) / 3`，先乘后除是为了让整数除法自动向下取整。

## 二、排序与查找（4 题）

排序本身很少是答案，它只是把「乱序比较」变成「有序比较」。四道题里三道排完序用 `lower_bound`／`upper_bound`，一道把值域直接当下标。

| 题号 | 题目 | 期 | 难度 | 要点 |
|---|---|---|---|---|
| CF706B | Interesting drink | 2 | 10 | 价格排序，`upper_bound` 求不超过 m 的个数 |
| P1116 | 车厢重组 | 1 | 13 | 冒泡交换次数等于逆序对数；sort 记原位置后双重循环数 |
| CF1742D | Coprime | 4 | 19 | 值域只有 1–1000，记每个值最后出现的下标，枚举值对判 `gcd` |
| AT_arc084_a | Snuke Festival | 1 | 19 | 枚举中间数组 B，A 里比它小的个数乘 C 里比它大的个数 |

ABC077 C 的关键是「枚举中间那一层」，枚举上下两层都拆不开：

```cpp
sort(A.begin(), A.end());
sort(C.begin(), C.end());

long long ans = 0;
for (int b : B) {
    long long left  = lower_bound(A.begin(), A.end(), b) - A.begin();  // < b 的个数
    long long right = C.end() - upper_bound(C.begin(), C.end(), b);    // > b 的个数
    ans += left * right;
}
```

CF1742D 值域只有 1000，直接用值当下标，省掉一层排序：

```cpp
int last[1001] = {};
for (int i = 1; i <= n; i++) {
    int v; cin >> v;
    last[v] = i;                      // 同一个值只留最后出现的下标
}

int best = -1;
for (int i = 1; i <= 1000; i++)
    for (int j = i; j <= 1000; j++)   // j 从 i 开始，允许 i == j
        if (last[i] && last[j] && gcd(i, j) == 1)
            best = max(best, last[i] + last[j]);
```

要记得：

- `lower_bound` 是第一个大于等于 x 的位置，`upper_bound` 是第一个严格大于 x 的位置。数「大于」的个数要用 `end() - upper_bound`，写成 `end() - lower_bound` 会把等于 x 的也算进去。
- ABC077 C 枚举两层是 O(n²)，10⁵ 会超时。拆成「左 × 右」之后是 O(n log n)。
- P1116 用 sort 加双重循环是 O(n²)，n ≤ 1000 够用。n 到 10⁵ 就得换树状数组或归并排序求逆序对。
- CF1742D 里 `j = i` 不能写成 `j = i + 1`：`gcd(a, a) = a`，只有 a = 1 时合法，但那种情况确实存在。
- CF706B 的查询次数到 10⁵，每次都要二分，不能每个查询重新扫一遍。

## 三、前缀和与计数（4 题）

前缀和把区间查询压成 O(1)。四道题是四种用法：字符权值求和、差值分组、0/1 转正负、异或前缀。

| 题号 | 题目 | 期 | 难度 | 要点 |
|---|---|---|---|---|
| CF1539B | Love Song | 3 | 9 | 每个字母的值做前缀和，区间就是 `pre[r] - pre[l-1]` |
| CF1520D | Same Differences | 4 | 19 | `a_j - a_i = j - i` 移项成 `a_j - j = a_i - i`，同值分组计数 |
| CF873B | Balanced Substring | 1 | 22 | 0 记 −1、1 记 +1，前缀和相同的最远两点之间就是答案 |
| CF1718A1 | Burenka and Traditions | 3 | 40 | 异或前缀和相等，说明中间这段整体异或为 0，可以少付一次代价 |

CF873B：前缀和相同的两个位置之间，0 和 1 的个数必然相等。

```cpp
vector<int> first(2 * n + 1, -1);
first[n] = 0;                       // 加偏移 n，避免负下标
int cur = 0, ans = 0;

for (int i = 0; i < n; i++) {
    cur += (s[i] == '1' ? 1 : -1);
    int idx = cur + n;
    if (first[idx] == -1) first[idx] = i + 1;      // 只记第一次到达
    else ans = max(ans, i + 1 - first[idx]);
}
```

CF1520D：把二维的配对条件压成一维计数。

```cpp
map<int, int> cnt;
long long ans = 0;

for (int i = 1; i <= n; i++) {
    int a; cin >> a;
    int key = a - i;
    ans += cnt[key]++;              // 之前出现过几次，就新增几对
}
```

要记得：

- 前缀和数组开 `n+1`，`pre[0] = 0`，区间 `[l, r]` 是 `pre[r] - pre[l-1]`。开 `n` 的话 l = 1 就下标越界。
- CF873B 的 `first` 只在第一次到达时写入。后面再经过同一个值不能覆盖，覆盖了最长长度就变短。
- 前缀和会走到负数，要么加偏移（这里是 `+n`），要么换成 `map<int,int>`。
- CF1718A1 的难点不在前缀和，在「异或和为 0 的区间能省一次操作」这个结论。切出一段后要清空 set、把前缀异或归零，不重叠才最优。
- CF1520D 的答案可能到 10¹⁰ 量级，`ans` 要用 `long long`。

## 四、滑动窗口（2 题）

连续区间、并且判断量随区间变大单调变化，就用同向双指针。

| 题号 | 题目 | 期 | 难度 | 要点 |
|---|---|---|---|---|
| U729723 | 天才般的拆分 | 5 | 15 | 两端各取 k 个字符比对称，中间至少留 1 个，即 `n - 2k ≥ 1` |
| CF1692E | Binary Deque | 1 | 19 | 求「和恰好为 s 的最长子数组」，答案 `n - 最长长度` |

CF1692E 的转换：最少从两端删几个，等于总数减去能保留下来的最长一段。

```cpp
int L = 0, cur = 0, best = -1;

for (int R = 0; R < n; R++) {
    cur += a[R];
    while (cur > s && L <= R) cur -= a[L++];
    if (cur == s) best = max(best, R - L + 1);
}

cout << (best == -1 ? -1 : n - best);
```

要记得：

- 滑窗成立的前提是「窗口变大，被判断的量单调不减」。全是正数才成立，出现负数就只能换前缀和加哈希。
- CF1692E 要先判两种边界：总和小于 s 直接 −1，总和等于 s 直接 0。不判的话窗口可能一次都不命中，`best` 留在 −1。
- 窗口收缩用 `while` 不用 `if`：右边界移动一次，左边界可能要连续吐出好几个元素。
- U729723 的两端比较是 `s[i]` 对 `s[n-1-i]`，只看前 k 位，中间那段内容完全不用管。

## 五、贪心（2 题）

写法大同小异：定一个处理顺序，每步取当前最优，再说明为什么不会更差。两道题的顺序都是排序。

| 题号 | 题目 | 期 | 难度 | 要点 |
|---|---|---|---|---|
| CF230A | Dragons | 2 | 9 | 按龙的力量升序打，力量够就加奖励，不够直接 `NO` |
| CF1213B | Bad Prices | 1 | 11 | 从右往左维护后缀最小值，比它大的就是 bad day |

CF230A：先打弱的是唯一正确的顺序，因为打任何一条龙都只增不减力量。

```cpp
sort(d, d + n, [](const Dg& p, const Dg& q) { return p.x < q.x; });

for (int i = 0; i < n; i++) {
    if (s <= d[i].x) { cout << "NO\n"; return 0; }   // 力量必须严格大于
    s += d[i].y;
}
cout << "YES\n";
```

要记得：

- CF230A 要求力量**严格大于**龙的力量，判断写 `s <= d[i].x` 就 `NO`。写成 `s < d[i].x` 会漏掉相等的情况。
- CF1213B 从后往前扫一遍就够。对每个 i 再扫一遍后缀是 O(n²)，n = 1.5×10⁵ 必超时。
- 贪心写完要能说清「为什么这样排不会更差」。说不出理由的那一步，通常就是反例所在。

## 六、二分答案（2 题）

问「最小／最大的某个值」，并且 `check(v)` 随 v 单调变化，就二分这个值，不去二分下标。

| 题号 | 题目 | 期 | 难度 | 要点 |
|---|---|---|---|---|
| CF1873E | Building an Aquarium | 4 | 17 | 二分水位 h，`check` 算 `Σ max(0, h - a_i) ≤ x` |
| CF2280C | Reverse and Double | 4 | 36 | 二分最大差 v，`check` 数坏点、枚举反转区间 |

二分答案的骨架，求最大可行解：

```cpp
int L = 0, R = 1e9 + 100, ans = 0;

while (L <= R) {
    int mid = L + (R - L) / 2;
    if (check(mid)) { ans = mid; L = mid + 1; }   // 可行，往更大试
    else              R = mid - 1;               // 不可行，往更小退
}
cout << ans;
```

CF1873E 的 `check`，只有低于水位的格子才吃水：

```cpp
bool check(long long h) {
    long long need = 0;
    for (int i = 0; i < n; i++)
        if (a[i] < h) {
            need += h - a[i];
            if (need > x) return false;      // 边加边判，别等加完
        }
    return true;
}
```

要记得：

- `mid = L + (R - L) / 2`，不写 `(L + R) / 2`。L、R 接近 2×10⁹ 时相加会溢出。
- 「求最大可行」可行就 `L = mid + 1`，「求最小可行」可行就 `R = mid - 1`。方向写反会死循环或者答案差一位。
- CF1873E 的水量用 `long long`：10⁵ 个格子、水位 10⁹，`int` 撑不住，而且 `need` 在累加过程中就会溢出。
- CF2280C 的 `check` 要分四种情况：没有坏点直接真、坏点三个以上直接假、两个坏点时切口唯一、一个坏点时往左右两个方向各枚举一次。

## 七、构造（7 题）

构造题没有通解，套路就那几个：凑特殊值（0、1、相等）、按余数分类、按整除分段。先看样例能不能反推，不行就从小规模枚举找规律。

| 题号 | 题目 | 期 | 难度 | 要点 |
|---|---|---|---|---|
| U729739 | 数列构造 | 5 | 11 | 和为偶数且长度上限不少于 2 时，`{s/2, s/2}` 的异或必为 0 |
| CF1659A | Red Versus Blue | 1 | 14 | b 个 B 把串切成 b+1 段，`q = r/(b+1)`、`rem = r%(b+1)`，前 rem 段各多放一个 |
| CF1343B | Balanced Array | 3 | 14 | 前 n/2 个偶数、后 n/2 个奇数，最后一个补 `n + n/2 - 1`；只有 `n % 4 == 0` 有解 |
| U728941 | 绀碧绝音 | 5 | 18 | 设操作次数 x2、x3、x4，逆推出五个方程，判非负和一致性 |
| CF907A | Masha and Bears | 3 | 19 | `vm >= v2` 或 `max/min > 2` 判 −1，否则输出 `2v1`、`2v2`、`max(v3, vm)` |
| CF2092B | Lady Bug | 3 | 22 | 按奇偶位分成两组，各数 1 的个数，与 `n/2`、`(n+1)/2` 比较 |
| CF1617B | GCD Problem | 3 | 23 | 固定 `c = 1`，把 `n-1` 拆成两个互质的数 |

CF1659A：把 r 个 R 尽量平均塞进 b+1 个空档，多出来的分给前面几段。

```cpp
int q = r / (b + 1), rem = r % (b + 1);

for (int i = 0; i <= b; i++) {
    int cnt = q + (i < rem);
    cout << string(cnt, 'R');
    if (i < b) cout << 'B';
}
```

CF1617B：c 固定成 1，问题就变成「把 n−1 拆成两个互质数」。

```cpp
if (n % 2 == 0) {
    cout << n / 2 - 1 << ' ' << n / 2 << ' ' << 1;   // 相邻两数必互质
} else {
    int m = (n - 1) / 2;
    if (m % 2 == 0) cout << m + 1 << ' ' << m - 1 << ' ' << 1;   // 差 2，两个奇数
    else            cout << m + 2 << ' ' << m - 2 << ' ' << 1;
}
```

要记得：

- CF1659A 的余数分给前 rem 段，不是最后一段。堆到末尾就会连续出现 R。
- CF1343B 的判据是 `n % 4 == 0`。`n % 4 == 2` 时两组的和相差 `n/2`，这是个奇数，而调换一个奇数位置上的元素只能让差变化偶数，永远凑不平。
- CF907A 的两个条件都要写：`vm >= v2` 和 `max(vm,v3) > 2*min(vm,v3)`。少一个就 WA。
- CF1617B 的 n 从 4 开始，n = 4 时走偶数分支输出 `1 2 1`，能过。
- 构造题答案不唯一，满足条件就算对。不要纠结「样例为什么这样输出」。

## 八、数学与结论（6 题）

代码都很短，难度全在推式子。共同点：先把条件写成等式或不等式，化简到能算，最后才写代码。

| 题号 | 题目 | 期 | 难度 | 要点 |
|---|---|---|---|---|
| U729735 | 光圈 | 5 | 5 | 每次反射走过 p 个等分点，k 次后位置是 `(p*k) % n` |
| CF2276A | Perfect Sandwiches | 4 | 9 | 约束化简成一条，答案 `min(b, a-b)` |
| CF1374B | Multiply by 2, divide by 6 | 1 | 13 | 只能消掉 2 和 3 的因子；一次 `/6` 抵一次 `*2` 加一次 `/3` |
| CF2013B | Battle for Survive | 1 | 16 | 答案是 `a[n] - a[n-1] + Σa[1..n-2]`，把 a[n-1] 压到最小 |
| U729727 | 向量 | 5 | 21 | `ab+bc+ca = (‖a+b+c‖² - Σr²) / 2`，用三角形不等式定合向量最小值 |
| U730339 | 铁花飞 | 5 | 26 | `a(1+x+xy) = n`，枚举 a，再枚举 `n/a - 1` 的因数对 |

U729727：先把平方展开，再看三个向量能不能围成三角形。

```cpp
long long sum = r1*r1 + r2*r2 + r3*r3;

if (r1 + r2 >= r3) {                                  // 能闭合，合向量为 0
    cout << -(sum / 2) << (sum & 1 ? ".5" : ".0") << "\n";
} else {                                              // 闭合不了，合向量长 r3-r1-r2
    cout << r1*r2 - r1*r3 - r3*r2 << ".0\n";
}
```

U730339：`q = n/a`，`q-1` 要拆成 `x` 和 `y+1`，两个因数各有下界。

```cpp
long long count_pairs(long long m) {        // 数 m 的因数对 (f, m/f)
    long long res = 0;
    for (long long f = 1; f * f <= m; f++) {
        if (m % f) continue;
        long long g = m / f;
        if (f > 1 && g > 2) res++;
        if (f != g && g > 1 && f > 2) res++;
    }
    return res;
}
```

要记得：

- U729735 的 p、k 到 10⁹，`p*k` 到 10¹⁸ 会溢出 `int`。先各自取模再乘，最后再取一次模。
- CF1374B 的终止条件是变成 1。出现 5、7 这种消不掉的因子直接 −1，不要死循环。
- U729727 输出是 `.0`／`.5` 结尾的字符串。拿 `double` 算一半会出现 `-0.4999999` 这种，直接按整数算、按奇偶补小数最稳。
- U730339 枚举因数只到 `√m`，`f` 和 `m/f` 是两种不同方案，`f == g` 时只算一次。
- 这类题的代码长度和难度基本无关。式子推不出来，写一百行也没用。

## 九、动态规划（1 题）

前五期只有一道 DP，但它把 LIS 正反两遍的用法讲全了。

| 题号 | 题目 | 期 | 难度 | 要点 |
|---|---|---|---|---|
| P1091 | 合唱队形 | 2 | 22 | 正着求一遍 LIS、反着求一遍 LIS，答案 `n - max(l[i] + r[i] - 1)` |

```cpp
for (int i = 1; i <= n; i++) {                    // l[i]：以 i 结尾的最长上升子序列
    l[i] = 1;
    for (int j = 1; j < i; j++)
        if (a[j] < a[i]) l[i] = max(l[i], l[j] + 1);
}

for (int i = n; i >= 1; i--) {                    // r[i]：以 i 开头的最长下降子序列
    r[i] = 1;
    for (int j = n; j > i; j--)
        if (a[j] < a[i]) r[i] = max(r[i], r[j] + 1);
}

int best = 0;
for (int i = 1; i <= n; i++) best = max(best, l[i] + r[i] - 1);
cout << n - best;
```

要记得：

- 两遍都是严格比较 `a[j] < a[i]`。写成 `<=` 就成了不下降子序列，身高重复的人会被算两次。
- `l[i] + r[i] - 1` 要减 1，位置 i 被正反两遍各算了一次。
- 这题 n ≤ 100，O(n²) 够。n 到 10⁵ 要换成 `lower_bound` 的 O(n log n) 版本。
- 反着求下降，等价于把数组倒过来求上升。不用另写一套转移方程。

## 五期各考了什么 {: .newpage }

把五期摊开看，出题思路的变化比自己刷题的顺序更值得注意。

| 期 | 题数 | 考点分布 |
|---|---|---|
| 1 | 9 | 覆盖面最广的一期：模拟、排序加二分、滑动窗口、前缀和、贪心各来一道，难度跨 5–22 |
| 2 | 9 | 纯入门。从 A+B、分段计价、拆位计数到排序贪心、LIS，2 分和 22 分都在这一期 |
| 3 | 9 | 构造占 4 道，配桶计数、前缀和、奇偶分类，最后一道是异或前缀和加贪心 |
| 4 | 8 | 两道二分答案、两道「值域或差值」计数，剩下的又回到 Div3 的 A 题 |
| 5 | 9 | 全是自制题。5 道靠推式子（取模、约数、向量、逆推方程、异或构造），其余是模拟和双指针 |

第 2 期整期在补基础，第 4 期是「三道 A 题加两道二分答案」的组合，第 3、5 期明显往构造和数学上压。第 5 期没有一道是现成题目，说明出题人已经开始按自己的思路拼题了。

## 复习顺序

按分数从低到高做，一段做完再回头重写错的那几道。

- **10 分以内（19 道）**：只要不写错下标和边界，应该一次过。错在这里的题要重写一遍，光看没用。
- **11–20 分（16 道）**：主体部分。每道都要能说出「为什么用这个工具」，不只是能过。
- **21–30 分（6 道）**：P1091、U729727、CF873B、CF2092B、CF1617B、U730339。覆盖了 LIS、向量几何、前缀和、奇偶分类、数论构造、约数枚举，都是后面反复出现的原型。
- **31 分以上（2 道）**：CF2280C、CF1718A1。现在做不出来正常，等二分答案和异或前缀和练熟了再回来。

前五期没有一道到 45 分以上，说明卷子定位在 Div3 到 Div2 前中期。要往 60 分以上走，得开始碰线段树、并查集、最短路这些前五期没出现过的东西。
