① 拆位贡献 第二场 T5

a&1 奇偶 ｜ a&(a-1) 去末尾的 1 ｜ (a>>k)&1 取位 ｜ a<<k 乘 2^k

ll tot = 1LL*n*(n+1)/2, ans = 0;
for (int k = 0; k < 30; k++) {
    ll bad = 0, run = 0;
    for (int i = 0; i < n; i++) {
        if ((a[i] >> k) & 1) run = 0;
        else { run++; bad += run; }
    }
    ans = (ans + (tot-bad)%MOD * ((1LL<<k)%MOD)) % MOD;
}
三句话：① 各位独立，拆开算；② 正难则反，算「这一位全 0」的子数组数，再用总数减；③ 连续 0 段长 L 贡献 L(L+1)/2 个（代码里 bad += run 就是在累加 1+2+…+L）。枚举 0—29 位即可（a ≤ 1e9 < 2³⁰）。

② 相同值合并 + 桶 第二场 T7

vector<pair<int,ll> > pre, cur;   // 每种「与值」及出现次数
for (int j = 0; j < m; j++) {
    cur.assign(1, make_pair(b[j], 1LL));
    for (auto &p : pre) {
        int v = p.first & b[j];
        if (cur.back().first != v)
            cur.push_back(make_pair(v, 0LL));
        cur.back().second += p.second;
    }
    for (auto &p : cur) cnt[p.first] += p.second;   // 桶
    pre = cur;
}

外层怎么套：枚举上边界 r1 令 b[j]=a[r1][j]，再逐行下压 r2（先 b[j]&=a[r2][j]）后跑上面这段，就把二维压成了一维。
为什么能省：与运算只会让数变小，往左延伸的与值单调不增，最多变 30 次 → pre 长度 ≤ 30。值域 ≤ 1000 时直接开 cnt[1024] 统计，最后从头累加找中位数，不用排序也不用二分。总复杂度 O(n²m·30)。

③ 数论四件套 第一场 5

ll gcd(ll a,ll b){ return b ? gcd(b,a%b) : a; }
ll lcm(ll a,ll b){ return a / gcd(a,b) * b; }   // 先除后乘
ll qpow(ll a,ll b,ll mod){
    ll r = 1; a %= mod;
    while (b) { if (b&1) r = r*a%mod; a = a*a%mod; b >>= 1; }
    return r;
}
for (ll i = 1; i*i <= n; i++) if (n % i == 0) {
    // i 与 n/i 成对，一次枚举拿两个约数
}
for (int i = 2; i <= n; i++) if (!vis[i])       // 埃氏筛
    for (ll j = 1LL*i*i; j <= n; j += i) vis[j] = 1;

第一场 5 的推导（背下来直接拿分）：lcm/gcd = uv / g²，且 gcd(a+x, b+x) = gcd(a+x, |a−b|)。枚举 d = |a−b| 的每个约数 g，取最小正整数 x 使 g | (a+x)：x = (g - a%g) % g，x = 0 时改成 x = g（题要 x 为正整数，错这里样例就过不去）。a = b 时 d = 0，答案是 1。

A 组加餐 · 曼哈顿转切比雪夫 第二场 T6

u = x + y;   v = x - y;
|x1-x2| + |y1-y2|  ==  max(|u1-u2|, |v1-v2|)

菱形边框转 45° 就成了轴对齐矩形，四条边各是一段连续区间，套前缀最值。问「距离恰好为 k」的点，本质是在这四条边上取 max。

④ 线性 DP：状态 = 资源余额 第二场 T4

vector<ll> dp(m+1, -1);  dp[0] = 0;    // -1 = 到不了
for (int i = 0; i < n; i++) {
    vector<ll> ndp(m+1, -1);
    for (int j = 0; j <= m; j++) {
        if (dp[j] < 0) continue;
        if (j + b[i] <= m)                       // 学习
            ndp[j+b[i]] = max(ndp[j+b[i]], dp[j]+a[i]);
        int nj = max(0, j - (int)b[i]);          // 放松
        ndp[nj] = max(ndp[nj], dp[j]);
    }
    dp = ndp;                                    // 滚动数组
}

三步设计状态：① 这一步在决策什么（学 / 放松）② 决策完什么信息影响后面（压力值）③ 把那个量做成下标。放松后压力减 b[i]，减成负数按 0 算（钳位别忘）。非法态用 −1 或 −1e9 初始化，不要用 0，否则「到不了」会被当成「收益为 0」。
背包是同一套：01 背包容量维倒序、完全背包正序，差别只在这件物品能不能重复拿。

⑤ 并查集 10 行，最便宜

int fa[N];
void init(int n){ for (int i=1;i<=n;i++) fa[i]=i; }
int find(int x){
    return fa[x]==x ? x : fa[x] = find(fa[x]);   // 路径压缩
}
void merge(int a,int b){ fa[find(a)] = find(b); }
// 判连通：find(a) == find(b)

认题信号：「连通块」「合并」「是否同一组」「朋友圈」「等价关系」。46 题里的 P1596 水坑（八方向染色）用并查集也能做，可以拿来对拍。

⑥ STL 补漏 模拟题必备

deque<int> dq;   push_back / push_front / pop_back / pop_front
priority_queue<int,vector<int>,greater<int> > pq;   // 小根堆
map<string,int> mp;  mp[k]++;    // 不存在默认 0，最省事
set<int> s;  s.insert(x); s.count(x); s.erase(x);

string 三个坑：cin>>s 遇空格就停；读整行用 getline(cin,s)，前面有 cin>>n 时先 getchar() 吃掉换行；s.find(t) 找不到返回 npos，别拿去当下标。
你已练过栈（B3614）、队列（B3616）、堆（P3378）、后缀表达式（P1449）、合并果子（P1090）——只补 deque / map / set。
