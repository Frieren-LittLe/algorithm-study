**异或前缀和**（Prefix XOR Sum）和普通的**加法前缀和**几乎一模一样，只不过把“累加（$+$）”换成了“累异或（$\oplus$）”。

# 1.定义
对于数组$a_1,a_2,\dots,a_n$ ,定义第$i$个位置的异或前缀和$P_i$为前$i$个数的异或和（通常规定$P_0 = 0$）:
$$
P_i = a_1 \oplus a_2 \oplus \dots \oplus a_i
$$
递推求法非常简单，只要扫一遍数组：
$$
P_i = P_{i-1} \oplus a_i
$$ 
# 2.核心作用:$O(1)$求任意区间的异或和
- **普通加法前缀和**：想求区间$[l,r]$的和，用**减法**抵消掉前面多算的部分：
  $$
  sum(l,r) = S_r - S_{l-1}
  $$
- **异或前缀和**：想求区间$[l,r]$ 的异或和，用异或就能抵消掉前面多算的部分:
  $$
  xor(l,r) = P_r \oplus P_{l-1}
  $$
  **为什么能抵消？**
  因为异或满足**自反性**（相同的数异或等于0，即$x \oplus x = 0$；任何数异或0等于它自己，即$x \oplus 0 = x$）。把$P_r \oplus P_{l-1}$展开:
  $$
(a_1 \oplus \dots \oplus a_{l-1} \oplus a_l \oplus \dots \oplus a_r) \oplus (a_1 \oplus \dots \oplus a_{l-1})
  $$
  前面重复的$a_1 \sim a_{l-1}$全部两两抵消成0，最后只剩下$a_l \oplus \dots \oplus a_r$

# 3.举个例子
假设数组$a = [2,3,5,6]$,我们从左到右算它的异或前缀和$P$:
- $P_0 = 0$
- $P_1 = 0 \oplus 2 = 2$
- $P2 = 2 \oplus 3 = 1$
- $P3 = 1 \oplus 5 = 4$
- $P4 = 4 \oplus 6 = 2$
 注意看$P_1$和$P_4$**相等了**（都是2）:
 - 根据公式，区间$[2,4]$ （即$\{3,5,6\}$）的异或和 $= P_4 \oplus P_1 = 2 \oplus 2 = 0$
 - 实际验算一下:$3 \oplus 5 \oplus 6 = 0$,完全吻合！
 只要两个位置的异或前缀和相等($P_r = P_{l-1}$),它们中间夹着的区间$[l,r]$的异或和就一定是0
