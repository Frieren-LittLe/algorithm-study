# 0004洛谷B2003 输出第二个整数

```cpp
#include <iostream>
using namespace std;

int main() {
	int a, b, c;
```

int 的作用是存储整数，不来自任何头文件

```cpp
	cin >> a >> b >> c;
	cout << b << endl;
	return (0);
}
```

## 完整代码

```cpp
#include <iostream>
using namespace std;

int main() {
	int a, b, c;

	cin >> a >> b >> c;
	cout << b << endl;
	return (0);
}
```
