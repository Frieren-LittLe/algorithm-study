# 0006洛谷P1001 A+B Problem

算法竞赛中要求的输出格式中，不能有多余的内容，这也包括了“请输入整数 a 和b”这一类提示用户输入信息的内容

```cpp
#include <iostream>

using namespace std;

int main() {
	int a, b;
	cin >> a >> b;
	cout << a + b << endl;
	return 0;
}
```

## 完整代码

```cpp
#include <iostream>

using namespace std;

int main() {
	int a, b;
	cin >> a >> b;
	cout << a + b << endl;
	return 0;
}
```
