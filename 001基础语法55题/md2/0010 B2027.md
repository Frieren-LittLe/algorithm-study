# 0010洛谷B2027 计算球的体积

```cpp
#include <iostream>
#include <iomanip>

```

cmath的主要作用：提供丰富的数学函数

```cpp
using namespace std;

int main() {
	int r;
	cin >> r;
	double V = (4.0 / 3.0) * 3.14 * pow(r, 3);
```

pow源于头文件<cmath>   前面的r表示底数，后面的3表示幂数

tips：幂数是可以为负数的，例如：pow(r, -3) 就是"半径的立方的倒数"

```cpp
	cout << fixed << setprecision(5);
	cout << V << endl;
	return(0);
}
```

## 完整代码

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>

using namespace std;

int main() {
	int r;
	cin >> r;
	double V = (4.0 / 3.0) * 3.14 * pow(r, 3);

	cout << fixed << setprecision(5);
	cout << V << endl;
	return(0);
}
```
