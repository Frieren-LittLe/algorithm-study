# 0011洛谷P5708 三角形面积

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main() {
	double a, b, c;
	cin >> a >> b >> c;
	double p = (a + b + c) / 2;
	double d = sqrt(p * (p - a) * (p - b) * (p - c));
```

sqrt（x）在数学上等价于x的算数平方根，源于<cmath>

```cpp
	cout << fixed << setprecision(1);
	cout << d << endl;
	return(0);
}
```

## 完整代码

```cpp
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main() {
	double a, b, c;
	cin >> a >> b >> c;
	double p = (a + b + c) / 2;
	double d = sqrt(p * (p - a) * (p - b) * (p - c));

	cout << fixed << setprecision(1);
	cout << d << endl;
	return(0);
}
```
