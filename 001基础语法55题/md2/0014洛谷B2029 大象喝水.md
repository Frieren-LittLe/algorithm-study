```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
	int h, r;
	cin >> h >> r;
	double v = 3.14 * pow(r, 2) * h;
	int n = ceil(20000.0 / v);
```

ceil源于<cmath> ceil(20000.0/v)的意思是计算 20000 除以 v 的结果，然后向上（正方向）取整到最接近的整数

为什么用 20000.0 而不是 20000？

如果 v 是 int 类型，20000 / v 执行的是整数除法，会直接截断小数部分，这样ceil就没意义了，所以一定要带小数点

```cpp
	cout << n << endl;
	return(0);
}
```

## 完整代码

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
	int h, r;
	cin >> h >> r;
	double v = 3.14 * pow(r, 2) * h;
	int n = ceil(20000.0 / v);

	cout << n << endl;
	return(0);
}
```
