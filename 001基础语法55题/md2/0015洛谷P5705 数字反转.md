# 0015洛谷P5705 数字反转

```cpp
#include <iostream>
#include<algorithm>
```

<algorithm> 是 C++ 标准库中的算法头文件，它提供了大量通用的、作用于容器（如字符串、数组、向量等）的算法函数。

```cpp
using namespace std;

int main() {
	string s;
	cin >> s;

	reverse(s.begin(), s.end());
```

该句作用是将字符串 s 中的字符顺序完全颠倒过来。这个写法可以套用在任何容器上（字符串、数组、向量等），是一个通用的反转操作！

reverse表示反转,源于algorithm

s.begin()可以理解为"指向开头的指针"，同理s.end()就是指向结尾的指针

想表示从第 3 个位置开始（从0开始数） 没有s.begin(3)这种写法，有s.begin() + 3这种写法

```cpp
	cout << s << endl;
	return(0);
}
```

## 完整代码

```cpp
#include <iostream>
#include<algorithm>

using namespace std;

int main() {
	string s;
	cin >> s;

	reverse(s.begin(), s.end());

	cout << s << endl;
	return(0);
}
```
