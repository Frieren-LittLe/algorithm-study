重要：数组下标从 0 开始，所以有效范围是 0 到 104，数组a中下标最大的数为a[104]

for (int i = 0; i < n; i++) 的意思是：让 i 从 0 开始，每次加 1，当 i 等于 n 时停止，总共循环 n 次

for(1初始化计数器;2条件判断;3变量更新）{4满足条件时所执行的代码}

执行的顺序为1>2>4>3;当2不能满足时，程序自动退出循环;

## 完整代码

```cpp
#include <iostream>
using namespace std;

int main() {
	int n;
	cin >> n;
	int a[105];

	for (int i = 0;i < n;i++) {

		cin >> a[i];

	}
	int min_val = a[0];

	for (int i = 1;i < n;i++) {
		if (a[i] < min_val) {
			min_val = a[i];

		}
	}
	cout << min_val << endl;
	return 0;
}
```
