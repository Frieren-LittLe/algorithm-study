ASCII 码（读作 "阿斯克码"）是 美国信息交换标准代码 的缩写，简单说就是 「给每个字符编一个数字号」

ASCII 码能让计算机能存住字母、数字、符号，是 "字符和数字的翻译对照表"

你只需要记住 '0'=48、'A'=65、'a'=97 三个起点，其他全可以推算

## 完整代码

```cpp
#include<iostream>
using namespace std;

int main() {
	char s[6];

	cin.getline(s, 6);

	int ans = 0;
	for (int i = 0;s[i] != '\0';i++) {

		if (s[i] != ' ' && s[i] != '\n') {

			ans++;
		}
	}

	cout << ans << endl;
	return 0;
}
```
